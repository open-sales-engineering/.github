# Open Sales Engineering

Open Sales Engineering is a branch of [Synctune](https://github.com/synctune-io), focused on open-source tools for pre-sales and post-sales. We build software that helps technical sales teams spend less time on busywork and more time working with customers.

## Projects

| Repository | Focus |
| --- | --- |
| [open-field-engineer](https://github.com/open-sales-engineering/open-field-engineer) | A provider-neutral workbench for customer context, calls, demos, tickets, follow-ups, and knowledge, on the web and desktop. |
| [website](https://github.com/open-sales-engineering/website) | A dependency-free static website for Open Sales Engineering. |

Some repositories are currently private. GitHub access is required.
